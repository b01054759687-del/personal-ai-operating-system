# Decisions Log (Architecture Decision Records)

## ADR-0001: Creation of Personal AI Operating System
- **Date**: 2026-09-07
- **Status**: Accepted
- **Context**: Need a unified, cross-tool, vendor-agnostic repository for all AI assets.
- **Decision**: Establish personal-ai-operating-system on GitHub (Private) with a 10-module hierarchy.
- **Consequences**: GitHub becomes canonical source of truth; all tools act as downstream consumers.
