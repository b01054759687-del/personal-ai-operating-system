# Release Notes — Personal AI Operating System v1.0.0 (Foundation)
## Release Date: 2026-09-09
## Release Type: BASELINE_MAJOR

### Highlights
- **Canonical Architecture**: 11 numbered layers (`00-META` to `10-ARCHIVE`) hosted locally and synced with GitHub.
- **AI Workspace Manager Agent**: Autonomous system agent managing assets, registries, and governance.
- **One-Way Tool Adapters**: Native projection adapters for Antigravity, Claude, Cursor, and Windsurf.
- **Structured Knowledge & Memory**: Portable Markdown-based memory (`07-KNOWLEDGE/`) with ADRs and personal context.
- **Claude Desktop GitHub MCP**: Read-only Model Context Protocol integration.
- **Zero Deletion & Zero Secrets**: Strict constitutional enforcement of data preservation and credential hygiene.
