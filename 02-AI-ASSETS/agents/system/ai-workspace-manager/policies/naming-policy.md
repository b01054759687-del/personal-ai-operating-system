# Naming Policy: Standardized Kebab-Case Specification

## 1. Scope
Every asset, directory, script, and workflow managed by the AI Workspace Manager Agent must adhere to standardized naming conventions.

## 2. Rules
- **Canonical Directories**: Must strictly use lowercase kebab-case (e.g., mlaak-content-creator, erify-claims-and-plans).
- **File Extensions**:
  - Documentation and prompt specifications: .md
  - Machine-readable descriptors: .json
  - Manifests: *-MANIFEST.json
- **Prohibited Patterns**:
  - No uppercase letters in asset directory names.
  - No underscores (_) in canonical asset folder names (reserved only for legacy migration mappings).
  - No whitespace or special punctuation characters (@, #, !).
