# مولد الأدلة التشغيلية وتقارير البراند التفاعلية (Branded Playbook Generator)

استخدم هذه المهارة كلما طلب المستخدم إعداد دليل تشغيل، خطة استعادة عملاء، Playbook، أو تقرير تنفيذي لتقديمه لعميل بهوية بصرية مخصصة وملف ويب تفاعلي.

---

## 1. مرحلة الاستجواب التفاعلي (Interactive Interview)

قبل كتابة أي سطر كود أو نص، اسأل المستخدم دفعة واحدة بشكل مجمع عن النقاط التالية (إذا لم تكن متوفرة في السياق):
1. **اسم العميل/البراند وموقعه:** (اسم النشاط، المدينة، وأسماء الفروع).
2. **ألوان الهوية البصرية:** (اللون الرئيسي، اللون الثانوي/الذهبي/الرمادي، أو صورة اللوجو لاستخراج درجات الألوان منها بدقة).
3. **شرائح العملاء المستهدفة:** (مثلاً: 3-6 أشهر، 6-12 شهرًا، أكثر من سنة، أو شرائح مخصصة بحسب نوع النشاط).
4. **النظام وقنوات التواصل المستخدمة:** (اسم نظام الـ ERP أو الـ CRM، مثلاً Sewbt / Odoo / HubSpot، وقناة التواصل الأساسية مثل WhatsApp Cloud API).
5. **طبيعة الخدمة/المنتج والهدف:** (مثلاً: تفصيل ثياب، عيادات، بيع تجزئة، استشارات، وما هو هدف الخطة: إعادة تنشيط، مبيعات مباشرة، خدمة عملاء).
6. **اللهجة المطلوبة:** (الافتراضي: اللهجة المصرية المبسطة والمهنية، أو لهجة خليجية/سعودية حسب طلب العميل).

## 2. الهيكلة الإلزامية للمحتوى (Zero-Fluff Structure)

يجب أن يحتوي الدليل الناتج على الأقسام الـ 14 التالية مع الحفاظ على التنسيق المباشر بدون حشو إنشائي:

1. **الهدف وأساسيات الشغل (Core Principles):** الثوابت التشغيلية وقواعد تجربة العميل (الاحترام، الخصوصية، الشفافية، التحكم، والخدمة قبل البيع).
2. **تقسيم العملاء وترتيب الإطلاق (Segmentation & Rollout):** جدول يحدد الشريحة، حالة العلاقة، الهدف الأول، وموعد التذكير، متبوعاً بترتيب الإطلاق.
3. **التجهيزات التقنية (Technical Readiness):** مخطط Mermaid لرسم علاقة المنصة بالـ API (مثل Meta و Sewbt) مع شروط الإيقاف الفوري في حال تعطل الربط.
4. **مسارات سير العمل للشرائح (Phased Workflows):**
   - رسم مخطط تدفق رأسي (`flowchart TD`) لكل شريحة يوضح نقطة البداية، فحص الرد، التذكير، والخيارات.
   - **هام جداً:** وضع صندوق الرسالة المعتمدة الأولى لكل مسار مع الأزرار التفاعلية **أسفل المخطط مباشرة**.
5. **المسارات الموحدة للردود (Unified Routing):** مخطط تدفق وشجرة قرارات توضح كيف تتجمع كل الشرائح في مسارات موحدة بعد رد العميل (راضي، مهتم، شكوى، مش دلوقتي، إيقاف).
6. **مسار الشكاوى واستعادة الثقة (Complaint Resolution):** مخطط تدفق دقيق للتعامل مع الشكوى من الاستماع والتسجيل وحتى الحل أو التصعيد والتعويض، مع التأكيد على قاعدة "عدم الاعتذار أو تقديم خصم قبل فحص المشكلة".
7. **مسار تحويل الاهتمام إلى زيارة/بيع (Fulfillment & Post-sale):** خطوات حجز الموعد، تذكيرات الحضور، والمتابعة بعد الاستلام للتأكد من الرضا.
8. **مكتبة الرسائل التشغيلية الشاملة (Full Message Library - 15+ قوالب):**
   - قوالب جاهزة للنسخ واللصق تغطي كافة السيناريوهات (عميل راضي، عميل مهتم، اكتشاف التفضيلات، الرد على الشكوى، تحديث الشكوى، عميل ناسي البراند، استئذان مكالمة، تأكيد حجز، تذكير موعد، عدم حضور، متابعة بعد الاستلام، عميل غير مهتم، تأكيد إيقاف، ورسائل التذكير).
9. **إعدادات النظام وأسباب الانقطاع (System Statuses & Dropdowns):** جدول لربط أسباب انقطاع العميل مع الإجراء الميداني المطلوب.
10. **قواعد تشغيل فريق العمل (Operations & SLAs):** جدول قواعد التواصل (الحد اليومي، سرعة الرد، حد المحادثات المفتوحة، حد الشكاوى)، وجدول توزيع المسؤوليات (الموظف، السيستم، الفرع، الإدارة).
11. **إطار العروض (Offer Strategy):** بدائل العروض (قيمة مضافة vs خصم مالي) ومخاطر وميزات كل بديل، مع التأكيد على عدم تقديم عروض لأصحاب الشكاوى المفتوحة.
12. **خطة الاختبار والجدول الزمني (MVP Testing & Timeline):** جدول يحدد حجم العينات ومجموعات المقارنة (Control Groups) وبوابات اتخاذ القرار.

## 3. المعايير البرمجية والتصميمية (HTML / CSS Boilerplate)

يجب إنشاء ملف HTML كامل مستقل وقابل للفتح في أي متصفح بالخصائص التالية:
- يبدأ بـ `<!DOCTYPE html>` مع `dir="rtl"` و `lang="ar"`.
- استيراد خط **Tajawal** من Google Fonts:
  ```html
  <link href="https://fonts.googleapis.com/css2?family=Tajawal:wght@400;500;700;800&display=swap" rel="stylesheet">
  ```
- استيراد وتهيئة مكتبة **Mermaid.js** مع تمرير متغيرات ألوان الهوية:
  ```html
  <script src="https://cdn.jsdelivr.net/npm/mermaid/dist/mermaid.min.js"></script>
  <script>
    mermaid.initialize({
      startOnLoad: true,
      theme: 'base',
      themeVariables: {
        primaryColor: '#FFFFFF',
        primaryTextColor: '#111111',
        primaryBorderColor: '{{BRAND_GOLD}}',
        lineColor: '#111111',
        secondaryColor: '{{BRAND_GOLD}}',
        tertiaryColor: '#F8F9FA',
        fontFamily: 'Tajawal',
        edgeLabelBackground: '#FFFFFF',
      },
      flowchart: { curve: 'linear' }
    });
  </script>
  ```
- تصميم الهيدر بخلفية داكنة فاخرة (`#111111`) مع لون الهوية البصري للعنوان، وجسم التقرير بكروت بيضاء وجداول وظلال خفيفة راقية.
- حفظ الملف في مجلد تنزيلات المستخدم أو مجلد المشروع بصيغة `.html`.
