# User Profile, Domain Context, and Execution Rules

## 1. Professional Background
- **Industry Sector**: Interior Design & Finishing (مجال التشطيبات والديكور).
- **Critical Distinction**: NOT Real Estate development, though parallels exist.
- **Key Metrics**: Square meters (sqm), Cost Plus contracting, qualified leads, cost-per-meeting (CPM), and closed contracts.

## 2. Communication Standards
- **Arabic Language Style**: Egyptian Arabic dialect (اللهجة المصرية العامية المبسطة والودية).
- **RTL Container Requirement**: All Arabic text in chat responses and markdown reports must be wrapped in `<div dir="rtl" style="text-align: right;">` with an empty line before and after.
- **Tone**: Direct, factual, zero filler words (بدون مط أو حشو).

## 3. Operational Mode
- **Turbo Mode**: Autonomous end-to-end execution with zero interruptions or unnecessary clarifying questions.
- **Evidence Integrity**: Distinguish facts, verified metrics, and assumptions; test claims rigorously.
