# منظومة استخراج استمارات الزواج الشرعي (Telegram Marriage Form Extractor)

تُفعّل هذه المهارة تلقائياً كلما طلب المستخدم استخراج أو تحديث أو فلترة استمارات الزواج من قنوات ومجموعات التلجرام (مثل قناة "الميثاق الغليظ للزواج الشرعي").

---

## 🎯 الشروط والمعايير المستهدفة الافتراضية الصارمة (Default Target Criteria)

عند طلب الاستخراج، يتم تطبيق هذه الفلاتر الافتراضية تلقائياً ما لم يطلب المستخدم خلاف ذلك:

1. **نوع الاستمارات**: استمارات **العرائس (البنات)** فقط، واستبعاد استمارات الشباب والإعلانات وإعلانات التوافق.
2. **محل الإقامة الفعلي**: **القاهرة والجيزة فقط** (إعطاء الأولوية القصوى لمحل السكن الحالي الفعلي على محافظة المنشأ الأصلية).
3. **السن (Age)**: **أقل من 28 سنة** (`age < 28` أي 27.5 سنة أو أقل)، وتُسجل كأرقام إنجليزية وخلايا رقمية حقيقية (`Number`).
4. **الطول (Height)**: **165 سم أو أقل** (`height <= 165`).
5. **الحالة الاجتماعية**: **آنسة / عزباء (لم يسبق لها الزواج)** فقط (استبعاد المطلقات والأرامل ومن سبق لهن زواج).
6. **المؤهل الدراسي**: تشمل جميع المؤهلات مع إبراز المؤهل بوضوح في عموده.

## 📊 هيكل وتنسيق ملف الإكسيل (Excel Specifications)

- **اتجاه الشيت**: **RTL (من اليمين لليسار)**.
- **نوع الخلايا والأعمدة الموحدة**:
  - `محل الإقامة (المحافظة الموحدة)`: القاهرة / الجيزة / باقي المحافظات.
  - `نوع الحجاب (الموحد)`: (نقاب / خمار / حجاب شرعي واسع / حجاب عادي / طرحة).
  - `السن (رقم)`: أرقام إنجليزية (مع الكسور العشرية مثل `21.5`).
  - `الوزن كجم (رقم)`: أرقام إنجليزية.
  - `الطول سم (رقم)`: أرقام إنجليزية.
  - `السن الأدنى للزوج` و `السن الأقصى للزوج`: أرقام إنجليزية.
- **الحفاظ التام على ألوان وتنسيقات وملاحظات المستخدم (Zero Overwrite Policy)**:
  - عند تحديث ملف الإكسيل، يجب قراءة التنسيقات والألوان (Fills/Themes/Highlights) والملاحظات التي وضعها المستخدم على أي صف أو خلية مسبقاً، وإعادة تطبيقها بالكامل على نفس الاستمارات دون مسحها أو إتلافها.
  - تفعيل خاصية الفلترة التلقائية (Excel Auto-Filter) على رأس الجدول لتسهيل الفلترة والتمييز.
- **تبويبات الملف (Worksheet Tabs)**:
  - Tab 1: **`المستهدفة (القاهرة والجيزة)`** (تضم الاستمارات المطابقة لجميع الشروط أعلاه).
  - Tab 2: **`كل القاهرة والجيزة`** (تضم جميع استمارات القاهرة والجيزة للاطلاع الأوسع).
- **التنسيق البصري**:
  - ترويسة كحلية أنيقة (`#1F4E78`) بنص أبيض عريض.
  - تفعيل الفلاتر التلقائية (Auto-Filter) عبر جميع الأعمدة.
  - تظليل الصفوف التبادلي (Zebra Striping).
  - روابط تليجرام تفاعلية مباشرة (`https://t.me/mMmo7v/[id]`).
